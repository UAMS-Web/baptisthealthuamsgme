# Theme features

Written against v1.3.3.

What the theme turns on or changes, beyond its widget areas and templates.

## Menus

| Location | Label | Where it appears |
| --- | --- | --- |
| `primary` | Primary Navigation Menu | Below the header |
| `footer` | Footer Navigation Menu | Above the site footer, on every page except the Landing template |

Assign menus under *Appearance*, *Menus*. Genesis's secondary menu location is not registered. Both menus collapse into a toggle button on small screens, labeled **Menu** and **Footer Menu**, and their dropdowns open from the keyboard.

## Color styles

Under *Genesis*, *Theme Settings*, *Color Style*, choose the default or one of **Purple**, **Green** or **Red**.

## Layouts

The layouts Genesis offers, less the three that use a secondary sidebar: Content, Sidebar; Sidebar, Content; and Full Width Content remain.

## Image sizes

| Name | Size | Used for |
| --- | --- | --- |
| `feature-large` | 960 by 330, cropped | The featured image above a single post |
| `leadership` | 210 by 280, cropped | Portraits in the Leadership template's widget area |

A single post with a featured image shows it above the content, as part of the content, so it also appears in the feed.

## Other behavior

- **Custom background** is supported, and a background image set under *Appearance*, *Customize* is stretched to fill the screen by the Backstretch script.
- **Right-to-left languages** load `style-rtl.css` in place of `style.css`.
- **Accessibility:** Genesis's skip links, 404 page and heading features are on; the search form has a label; post archives use WordPress's numbered pagination in place of Genesis's.
- **Footer text** reads the copyright year and a link to the site.
- **Fonts** are loaded from Google Fonts.

## Suggested plugins

In the admin, the theme suggests three optional plugins: Better Font Awesome, Genesis eNews Extended and WP Accessibility. None is required.
